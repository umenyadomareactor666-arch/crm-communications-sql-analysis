# SQL pet-project: Анализ эффективности CRM-коммуникаций

## 1. Бизнес-задача

Оценить эффективность CRM-коммуникаций по клиентской базе банка и понять:

- какие кампании дают лучший отклик;
- какие каналы эффективнее: push, sms, email;
- какие сегменты клиентов лучше конвертируются;
- есть ли uplift относительно контрольной группы;
- кого можно отобрать для повторной коммуникации.

Проект имитирует задачу аналитика, который получает требования от бизнеса, анализирует источники данных, пишет SQL-запросы, проверяет качество данных и готовит выводы для принятия решений.

## 2. Данные

В проекте используются синтетические данные:

| Таблица | Описание |
|---|---|
| `clients` | клиентская база: возраст, город, сегмент, активность |
| `campaigns` | CRM-кампании, канал, продукт, дата старта |
| `campaign_audience` | аудитория кампаний, test/control группы |
| `messages` | отправленные сообщения и статус доставки |
| `message_events` | события коммуникаций: sent, delivered, opened, clicked |
| `loan_applications` | заявки клиентов после коммуникаций |

## 3. Что сделано

- Проведено профилирование клиентской базы и источников данных.
- Проверены дубли, пропуски и логические ошибки в событиях.
- Построена воронка CRM-коммуникаций: отправка → доставка → открытие → клик → заявка → одобрение.
- Посчитаны delivery rate, open rate, CTR, conversion rate.
- Проведено сравнение test/control групп и рассчитан uplift.
- Выделены наиболее эффективные кампании и клиентские сегменты.
- Сформирована SQL-выборка клиентов для повторной коммуникации.

## 4. Использованные SQL-навыки

- `JOIN`
- `GROUP BY`
- `CASE WHEN`
- `CTE`
- агрегатные функции
- оконная логика через группировки
- проверка качества данных
- расчет метрик и конверсий
- подготовка клиентских выборок

## 5. Как запустить

Проект рассчитан на PostgreSQL.

```bash
createdb crm_project
psql -d crm_project -f sql/schema.sql
psql -d crm_project -f sql/load_data_postgres.sql
psql -d crm_project -f sql/analysis.sql
```

## 6. Главный результат

Проект показывает полный цикл работы аналитика данных: от понимания бизнес-задачи и структуры источников до SQL-расчётов, проверки качества данных и подготовки аналитических выводов.
